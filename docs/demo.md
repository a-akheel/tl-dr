# Two-minute demo

## Before presenting

Follow the README setup. Open the app, use **Try a sample**, create a summary once to warm language resources, and check the Word download. This demonstration uses a fictional customer-rollout note.

## Walkthrough

1. **0:00–0:20 — Set the problem.** “A reviewer has a long implementation note and wants a quick first pass before reading the full document.” Ask what information the reviewer must retain.
2. **0:20–0:50 — Show the workflow.** Click **Try a sample**, choose three sentences, and create the summary. Explain that selected sentences retain their original wording and source order.
3. **0:50–1:15 — Discuss evidence.** Show the actual word reduction and processing time. Explain that these measure compression and computation, not accuracy or customer time savings. Compare the summary with the source and identify an important omitted detail, such as single sign-on.
4. **1:15–1:35 — Complete the task.** Download the Word document. Demonstrate a TXT or DOCX upload if useful.
5. **1:35–2:00 — Explain fit and next steps.** Describe the ingestion → scoring → results → export architecture. Propose evaluating factual coverage and observed task time on representative customer documents before deciding whether to integrate or deploy.

## Recovery paths

- Scanned PDF: use a document with selectable text or paste the text; OCR is not implemented.
- Unreadable article: paste the article text; dynamic pages and paywalls are not supported.
- Expired download: generate a fresh summary.
- Overlong input: use an excerpt within the stated limits.
